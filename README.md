# AI CCTV Surveillance and Alert System

An AI-powered CCTV surveillance system developed for industrial and company security applications using Computer Vision and Python.

This project contains two intelligent real-time monitoring systems:

1. Vehicle Zone Intrusion Alert System
2. Smart Gate Open Delay Alert System

---

# Features

- Real-time CCTV monitoring
- AI-based object detection
- Restricted zone monitoring
- Gate status monitoring
- Image capture during alerts
- Telegram notification alerts
- Works with CCTV/live camera/video files
- Lightweight and customizable
